# AI城建系统

AI城建系统是一个智能城市建设管理平台，提供项目管理、资金安排、数据可视化和智慧报表生成功能。

## 功能特性

### 🏗️ 基础数据管理
- **项目基本信息表**：管理项目名称、编码、建设单位、主管部门、立项时间、概算批复金额、开工完工时间、项目状态等信息
- **资金安排表**：管理资金批复金额、批复日期、资金性质（一般债券、专项债券等）、经办人等信息
- **重点项目清单**：管理重点项目的优先级和特征信息
- **Excel导入导出**：支持Excel文件的导入导出，方便数据交换
- **模拟数据生成**：自动生成200个模拟项目和1000条资金安排数据用于测试

### 📊 数据可视化
- **项目状态分布图**：饼图展示项目状态分布
- **概算金额分布图**：直方图分析项目概算金额分布
- **资金性质分析图**：条形图展示不同资金性质的金额统计
- **项目时间轴图**：甘特图展示项目时间安排
- **债券资金统计图**：专门分析债券资金使用情况
- **部门项目数量统计**：各部门项目数量对比
- **月度资金安排趋势**：时间序列分析资金安排趋势
- **项目完成度分析**：项目完成情况统计分析

### 📋 智慧报表生成
- **项目总览报表**：项目基本信息汇总
- **资金安排报表**：资金安排详细信息
- **项目进度报表**：项目进度和完成情况分析
- **部门统计报表**：按部门统计项目和资金信息
- **债券资金报表**：债券资金专项分析
- **月度汇总报表**：按月份汇总数据
- **项目完成情况报表**：项目完成度统计
- **资金透视分析报表**：多维度资金分析，包含债券资金合计

## 安装和运行

### 环境要求
- Python 3.7+
- Windows 10/11, Linux, macOS

### 安装依赖
```bash
pip install -r requirements.txt
```

### 开发环境运行
```bash
python run.py
```

### 打包成可执行文件
```bash
python build.py
```

打包完成后，可执行文件位于 `dist/` 目录下。

### 创建桌面快捷方式
打包完成后，参考生成的 `desktop_shortcut_guide.txt` 文件创建桌面快捷方式。

## 使用指南

### 1. 基础数据管理
- 启动程序后，默认进入"基础数据管理"模块
- 点击"生成模拟数据"按钮生成测试数据
- 使用"导入Excel"和"导出Excel"功能进行数据交换
- 支持项目基本信息和资金安排数据的增删改查
- 点击"资金透视表"查看按项目编码分组的资金分析

### 2. 数据可视化
- 切换到"数据可视化"选项卡
- 选择不同的图表类型
- 点击"生成图表"查看可视化结果
- 使用"保存图表"功能导出图片

### 3. 智慧报表生成
- 切换到"智慧报表生成"选项卡
- 选择报表类型和日期范围
- 点击"生成报表"查看报表内容
- 使用"导出Excel"功能保存报表

## 数据库设计

### 项目基本信息表 (project_basic_info)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| project_name | TEXT | 项目名称 |
| project_code | TEXT | 项目编码（唯一） |
| construction_unit | TEXT | 建设单位 |
| supervising_department | TEXT | 项目主管部门 |
| approval_date | DATE | 立项时间 |
| budget_amount | REAL | 概算批复金额（万元） |
| planned_start_date | DATE | 预计开工时间 |
| planned_end_date | DATE | 预计完工时间 |
| project_status | TEXT | 项目状态（在建/续建/完工/暂停） |

### 资金安排表 (funding_arrangement)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| project_name | TEXT | 项目名称 |
| project_code | TEXT | 项目编码 |
| construction_unit | TEXT | 建设单位 |
| supervising_department | TEXT | 项目主管部门 |
| budget_amount | REAL | 概算批复金额（万元） |
| funding_amount | REAL | 资金批复金额（万元） |
| approval_date | DATE | 批复日期 |
| funding_type | TEXT | 资金性质 |
| operator | TEXT | 经办人 |
| operating_department | TEXT | 经办处室 |

### 资金性质类型
- 一般债券
- 专项债券
- 中央综合财力
- 土地出让金
- 中央预算内投资
- 中央补助
- 省级补助

## 特色功能

### 🔍 数据透视分析
系统提供强大的数据透视功能，可以按项目编码分组，展示每个项目不同资金性质的安排情况：
- 自动计算一般债券和专项债券的单独金额
- 生成债券资金合计字段
- 支持多维度数据分析

### 📈 智能图表生成
内置多种图表类型，自动根据数据生成美观的可视化图表：
- 支持中文字体显示
- 自动配色方案
- 交互式图表工具栏
- 高分辨率图片导出

### 📊 多格式报表导出
支持多种格式的报表导出：
- Excel格式（.xlsx）
- 图片格式（PNG、JPG）
- PDF格式（待实现）

## 技术栈

- **GUI框架**：tkinter + ttk
- **数据处理**：pandas + numpy
- **数据库**：SQLite3
- **数据可视化**：matplotlib + plotly
- **Excel处理**：openpyxl
- **打包工具**：PyInstaller
